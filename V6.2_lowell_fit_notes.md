# V6.2 Low-ℓ CMB Fit — Notes

## Purpose

`fit_cmb_lowell_v62.py` is a **preliminary phenomenological prototype** for
testing the IR-suppression hypothesis of the V6.2 CPT-Curvature framework
against the CMB large-angle TT power spectrum.

The goal is a minimal first-pass consistency check:

> Can the V6.2 low-ℓ suppression kernel reduce the quadrupole deficit and
> large-angle correlation suppression without over-fitting or destroying the
> baseline spectrum at ℓ > 30?

This is **not** a full Planck likelihood analysis and should not be cited as
one.  It is a first step to determine whether the direction is worth pursuing
in a more rigorous treatment.

---

## Model

The suppression kernel follows the V6.2 framework:

```
S_ell = f_LSS² / (1 + (ell / ell_IR)^p)

C_ell_model = C_ell_base × (1 − S_ell)
```

| Parameter | Symbol     | Physical meaning                                    |
|-----------|------------|-----------------------------------------------------|
| `f_LSS`   | f_LSS      | Amplitude: projection factor of the LSS boundary   |
| `ell_IR`  | ℓ_IR       | IR pivot multipole (transition scale)              |
| `p`       | p          | Transition sharpness exponent                      |

The suppression is maximal at ℓ → 0 and vanishes for ℓ ≫ ℓ_IR, leaving the
high-ℓ spectrum unaffected.

---

## Inputs

| Input            | Required | Description                                                     |
|------------------|----------|-----------------------------------------------------------------|
| CSV data file    | No       | Observed low-ℓ TT data: columns `ell`, `cl_obs`, [`sigma`]    |
| ell range        | No       | Default ℓ = 2 … 30                                             |
| Scan grid ranges | No       | Ranges and point counts for f_LSS, ℓ_IR, p                    |
| Output directory | No       | Directory for saved figures                                     |

If no CSV is provided the script generates a smooth toy baseline (Sachs-Wolfe
plateau shape) and uses it as mock observed data.  This lets the script run
out-of-the-box without any external data file.

If no `sigma` column is present in the CSV the script uses a
cosmic-variance-inspired approximation:

```
σ_ell ≈ √(2 / (2ℓ+1)) × C_ell_obs
```

## Running the Script

**Minimal (no data file):**
```bash
python fit_cmb_lowell_v62.py
```

**With observed data:**
```bash
python fit_cmb_lowell_v62.py --csv path/to/planck_lowell.csv --outdir results/
```

**Custom scan ranges:**
```bash
python fit_cmb_lowell_v62.py \
  --f-lss-min 0.05 --f-lss-max 0.9 --f-lss-n 30 \
  --ell-ir-min 2 --ell-ir-max 15 --ell-ir-n 28 \
  --p-min 2 --p-max 8 --p-n 7 \
  --ell-min 2 --ell-max 30 \
  --outdir results/
```

**Full help:**
```bash
python fit_cmb_lowell_v62.py --help
```

## Assumptions

1. **Isotropic suppression only.** The model modifies C_ell uniformly; it does
   not include any directional (anisotropic) effects (axis alignment, cold spot,
   TB/EB correlations).
2. **Phenomenological kernel.** The functional form of S_ell is a motivated
   proxy for the V6.2 IR boundary suppression.  It is not derived from a full
   solution of the modified field equations.
3. **Simplified uncertainties.** Without a full Planck covariance matrix, σ_ell
   is estimated via cosmic variance.  This under-estimates the true uncertainty
   and overstates the statistical significance of any fit improvement.
4. **No foreground, beam, or noise model.** A real CMB analysis requires
   careful treatment of sky masks, instrumental noise, and foreground residuals.
5. **Toy baseline (when no CSV given).** The internal baseline is a smooth
   analytic approximation, not a true ΛCDM spectrum from CAMB/CLASS.

---

## Limitations

- The chi-squared used here is not the Planck low-ℓ likelihood.  Results
  cannot be directly compared to published Planck constraints.
- The grid scan is coarse.  For publication-quality parameter constraints an
  MCMC or nested sampling approach would be required.
- Negative delta chi-squared does **not** constitute a detection; the
  statistical significance must be assessed against the number of extra
  parameters (AIC/BIC penalty).
- The script currently uses only the TT power spectrum.  The V6.2 framework
  also predicts signatures in TE, EE, and the angular correlation function
  C(θ) at θ > 60°.
